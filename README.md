Verifica tecnica di testi alternativi alt, compressione moderna e conformita agli standard W3C.

Sviluppato e mantenuto dalla divisione di architettura semantica e accessibilita di **TAVARDT**.

***

## Funzionalita di Verifica SEO per Immagini

* **Ispezione Attributi Alt e Accessibilita**: Analisi di copertura dei testi alternativi `alt`, rilevando elementi privi di descrizione.
* **Adozione Formati di Nuova Generazione**: Verifica dell'impiego di formati ad alte prestazioni (WebP e AVIF).
* **Stabilita Visuale e Mitigazione del CLS**: Controllo della presenza di attributi espliciti `width` e `height`.
* **Caricamento Differito (Lazy Loading)**: Ispezione delle direttive `loading="lazy"` per il risparmio di banda.
* **Punteggio di Ottimizzazione Visuale**: Metrica quantitativa da 0 a 100 con passaggi tecnici di ottimizzazione.

***

## Installazione ed Esecuzione

Richiede Python 3.8 o superiore, basato sulla libreria standard.

```bash
git clone https://github.com/TAVARDT-Italia/image-seo-validator-it.git
cd image-seo-validator-it
python image_seo_validator.py https://azienda.it
```

Per generare il rapporto in formato strutturato JSON:

```bash
python image_seo_validator.py https://azienda.it -json
```
